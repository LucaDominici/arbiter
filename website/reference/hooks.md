# Hook Script Inventory

Reference for all Claude Code hooks generated by Arbiter. Hooks enforce governance invariants at edit time, preventing violations before they reach the gate or CI.

Hooks are configured in `.claude/settings.json` and fire on Claude Code tool events.

All hooks are Node.js `.mjs` files — no bash required, no `chmod` needed, works on Windows without WSL.

---

## Hook Architecture

```
.claude/
  hooks/
    lib.mjs                   # Shared utilities (logging)
    stop-dangerous.mjs        # PreToolUse → Bash
    enforce-read-only.mjs     # PreToolUse → Edit|Write
    pre-edit-ssot-guard.mjs   # PreToolUse → Edit|Write
    post-commit-check.mjs     # PostToolUse → Bash
    check-no-orphan-todo.mjs  # PostToolUse → Edit|Write
    check-no-any.mjs          # PostToolUse → Edit|Write (TypeScript only)
    check-no-unwrap.mjs       # PostToolUse → Edit|Write (Rust only)
  settings.json               # Hook registration + permissions
```

Hooks read tool context from environment variables:

| Variable                    | Content                    |
| --------------------------- | -------------------------- |
| `CLAUDE_TOOL_INPUT_COMMAND` | The bash command being run |
| `CLAUDE_TOOL_INPUT_PATH`    | The file path being edited |

## Template-Generated Hooks

### `lib.mjs`

Provides `logInfo`, `logWarn`, `logError` functions. Writes to `.claude/hooks/logs/hook-events.log`.

### `post-commit-check.mjs`

| Property      | Value                                             |
| ------------- | ------------------------------------------------- |
| **Event**     | `PostToolUse` → `Bash`                            |
| **Purpose**   | Verify commit message follows conventional format |
| **Invariant** | Commit convention (AGENTS.md Commit Convention)   |
| **Timeout**   | 3 seconds                                         |
| **Blocking**  | No (warning only)                                 |

Triggers only on `git commit` commands. Checks the last commit message against the pattern:

```
^(feat|fix|refactor|test|docs|ci|chore|perf|style|build|revert)(\([^)]+\))?: .{1,72}$
```

## Code-Generated Hooks (Language-Specific)

### `check-no-orphan-todo.mjs`

| Property      | Value                               |
| ------------- | ----------------------------------- |
| **Event**     | `PostToolUse` → `Edit\|Write`       |
| **Purpose**   | Every TODO must reference a task ID |
| **Invariant** | INV-21                              |
| **Blocking**  | Yes (exit 1)                        |

Scans the edited file for `TODO` not followed by `(#NNN)`.

## Advanced Hooks (M17)

Generated for all governed projects. Phase-aware, context-injecting, state-preserving. All exit 0 (non-blocking).

### `pre-compact.mjs`

Fires before automatic context compaction. Reads `.claude/.task-*` state files and outputs a structured banner to stdout, injected into the model's context after compaction.

### `pre-edit-plan-anchor.mjs`

Phase-aware: only fires during `implementation` phase. Outputs the first 20 lines of the active plan file to stdout before each edit.

### `post-edit-dispatch.mjs`

Fires after every file edit. Runs `formatCommand` then `lintCommand` for source files. L2+ only.

### `debug-state-on-failure.mjs`

Fires only on bash command failures matching test/gate patterns. Creates `.evidence/debug/DEBUG_STATE.md` with failure context. L2+ only.

### `skill-forced-eval.mjs`

Fires before every user prompt. Phase-aware skill activation nudge. L2+ only.

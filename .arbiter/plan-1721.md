# Plan: Issue #1721 — generator-emitted llms.txt with --check drift mode (dogfood)

## Scope

Migrate the hand-authored `llms.txt` (currently only on unmerged branch
`worktree-karpathy-align` @ bc5de27f, NOT on main) to a generator-emitted
artifact: `scripts/gen-llms-txt.mjs` renders `llms.txt` from a new hand-owned
`llms-txt.config.json` + the live `docs/INDEX.md` doc count. `--check` mode
wired into the L1 gate immediately after the `doc index (#1102)` check.

## Existing Code Survey

**Target:** `scripts/gen-llms-txt.mjs` (NOT under `src/` — CANON-16 does not
hard-apply; survey done anyway per `.claude/rules/35-refactor-first.md`)

**Decision:** `new file justified`

### Evidence

- `grep -rl "export function runCli" scripts/*.mjs` → `gen-doc-index.mjs`, closest
  structural analog (exported `collectDocs`/`buildIndex`/`runCli`, `--check` byte
  compare, `isMain`-guarded CLI). Its `runCli` returns 1 on error (INV-53 says this
  generator should return 2 instead — do not copy that part).
- `grep -n "process.exit" scripts/gen-cli-ref.mjs` → exit-2-for-error discipline
  (0=OK/1=drift/2=error) — adopt this contract instead of gen-doc-index's.
- `ls scripts/lib/gen-doc-helpers.mjs` → shared helpers exist but contain no
  write-or-check helper; that block is inlined per-generator across
  gen-doc-index/gen-status/gen-gap/gen-ssot-core (4 near-copies already).

**Rationale (≥200 chars):** `llms.txt` is a distinct artifact (curated root
index) with a distinct source (new hand-owned config + docs/INDEX.md doc
count) and a distinct lifecycle from `docs/INDEX.md`'s frontmatter-driven
inventory. Extending `gen-doc-index.mjs` (which walks doc frontmatter) would
pollute its single responsibility with unrelated root-index curation logic.
Reusing the STRUCTURAL PATTERN (pure exported functions + isMain-guarded CLI +
`--check` byte-compare) while creating a new file keeps each generator's
responsibility clean and testable. The inlined write-or-check block is a
candidate 5th near-copy; run `node scripts/check-duplication.mjs` after
writing — if flagged, extract to `scripts/lib/gen-doc-helpers.mjs`.

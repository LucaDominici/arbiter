# Plan — #2905 configurable external reviewer model/effort (default gpt-6-luna / max)

## Context

`invokeCodex` in `src/integrations/external-review.ts` runs codex with no `-m` and no
`model_reasoning_effort`, so the review seat is the pinned CLI's default, and envelope provenance
does not record the engine. The owner chose gpt-6-luna at max (2026-09-25 replay). Premortem:
`.claude/plans/PREMORTEM_2905.md` §0 and §2. The change goes template→bake: the recorder script and
the agent-return schema have `.ejs` twins and example copies.

## Acceptance criteria

- AC-2905.1: the external reviewer's model and reasoning effort come from one config path, for example `ship.review.external.{model,effort}` in `arbiter.json` (overridable per run). The default is `gpt-6-luna` / `max`. Both are passed explicitly (`-m`, `-c model_reasoning_effort=`), never inherited.
- AC-2905.2: the envelope provenance records the model and effort actually requested.
- AC-2905.3: a test pins the argv (model and effort present), and the provenance fields.

## Decisions

- The config path is the existing `crossModelReview` block: `crossModelReview.{model,effort}` in
  `arbiter.json`. There is no per-run override and no new CLI option (the ceremony gate bans new CLI
  options); `arbiter.json` is the one path. The PR body states this deviation from AC-1's
  "overridable per run".
- Effort is a fixed set `low|medium|high|xhigh|max|ultra` (union from codex `models_cache.json`);
  the model is a token `^[A-Za-z0-9][A-Za-z0-9._:-]*$`. A model/effort mismatch is rejected API-side.
- Defaults live only in a private `reviewEngine()` in `external-review.ts`; one result feeds both
  the codex argv and the recorder provenance args. No new export.

## Non-goals

- A per-run override or CLI option.
- Enabling `crossModelReview` in Arbiter's own `arbiter.json` (needs the owner's egress consent).
- Adding the keys to `configure.ts` `ALLOWED_PATHS`.
- Changing the reviewer `timeoutMs` default (luna-max ≈825 s per review fits 900 000 ms).

## Design

1. `CrossModelReviewConfig` (`src/wizard/types.ts`) gains optional `model` and `effort`.
2. `validateCrossModelReview` (`src/config/schema.ts`) calls a private `validateCrossModelEngine`.
3. `invokeCodex` adds `-m <model> -c model_reasoning_effort="<effort>"` after
   `--ignore-user-config`; `recorderArgs` adds `--provenance-model` and `--provenance-effort`.
4. `record-agent-return.mjs` (and its `.ejs` twin) stamps `provenance.model` / `provenance.effort`;
   `agent-return.schema.json` (and twin) gains `provenance.effort`. `npm run examples:regenerate`.
5. Docs: D8 in `docs/design/cross-model-review-config.md`.

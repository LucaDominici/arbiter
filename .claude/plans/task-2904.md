# Plan — #2904 round ≥2 reviews acceptance fit against the task base

## Context

From review round 2 onward the frozen review prompt labels the previous reviewed SHA as `Base SHA`
and egresses only the delta, while still asking for acceptance fit on every criterion. The reviewer
then reads the delta base as the task base (Viafera #4610 round 3 false CRITICAL). This plan takes
option (a) of AC-1 (premortem: `.claude/plans/PREMORTEM_2904.md` §1).

## Acceptance criteria

- AC-2904.1: a round after the first either (a) gives the reviewer the task base for acceptance fit and the delta only as the "changed since last round" focus, both labelled as such in the prompt; or (b) asks for acceptance fit only on the criteria the delta touches and carries the previous round's per-criterion PASS forward for the rest, bound by content hash of the files those criteria cite.
- AC-2904.2: the prompt never labels the previous round's SHA as "Base SHA" without saying it is the previous reviewed candidate, not the task base.
- AC-2904.3: a regression test renders the round-2 prompt and pins the chosen behaviour.

## Non-goals

- Option (b) of AC-1 (per-criterion PASS carry-forward by content hash).
- `merge-base` resolution of the task base when `origin/main` moved without a rebase (follow-up).
- Any change to `task-ship.ts`, round planning, or the round cap.

## Design

1. `resolveReviewBase(repoRoot, baseSha)` becomes `resolveTaskBase(repoRoot)`: it always resolves
   `origin/main`, so the egressed diff is the full task diff in every round.
2. A private `previousReviewedSha(baseSha)` keeps the empty-base refusal and returns the previous
   reviewed SHA or null.
3. `frozenReviewPrompt` renders `Task base SHA (acceptance fit)`, `Head SHA`, `Task diff`, and, in
   rounds ≥2 only, `Changed since last round (focus; previous reviewed candidate, not the task base)`.
4. `reviewScopeLine` labels the operator scope as `changed since last round` and says acceptance fit
   uses the task base.
5. Existing fixtures that never answered `rev-parse origin/main` get that answer; a dated line goes
   to `SHIP_REDESIGN_JOURNAL.md`.

# #2912 — per-task review-dispatch sidecar

## Acceptance Criteria

- AC-2912.1: After `lifecycle start` on a fresh task, `git status --porcelain` is empty: the shared dispatch sidecar committed by an earlier task is neither deleted nor rewritten.
- AC-2912.2: The review-completion check still refuses a sidecar that belongs to another task. It judges by the task field it already reads, not by the file's absence.
- AC-2912.3: A regression test runs `lifecycle start` in a repo whose HEAD tracks another task's sidecar, and asserts a clean tree.

## Non-goals

- Deleting the tracked legacy `.arbiter/agents-dispatched.json` (nothing writes it after this change; deletion is a follow-up).
- A new `src/` export, CLI option, or path helper in `src/`.
- Changing the `--sidecar=` override or any review verdict rule other than sidecar location.

## Design

See `.claude/plans/PREMORTEM_2912.md` §2.4. The review-dispatch sidecar moves to
`.arbiter/agents-dispatched/<sanitizeTaskId(id)>.json` (`#2912 → _2912.json`). One `.mjs` resolver in
`scripts/lib/evidence-binding.mjs` (`dispatchSidecarPath`, `locateDispatchSidecar`): task known → its
per-task file, else the legacy file only on strict `taskId` equality; task unknown (CI) → per-task files
whose `branch` equals HEAD (1 → it, 0 → legacy, >1 → exit 2). Writers write only the per-task path.
`invalidateTaskReceipts` removes only the task's own file, and the legacy file only when its `taskId`
matches. `src/` inlines the path with the existing `sanitizeTaskId`. `.gitignore` (repo + template)
un-ignores `.arbiter/agents-dispatched/*.json`. Identical edits in each twin; examples and bake
snapshots regenerated.

## Test strategy

RED file `__tests__/commands/review-sidecar-per-task-2912.test.ts`: (a) writer path, (b) invalidation
leaves another task's committed legacy sidecar byte-identical with a clean tree (AC-2912.1, AC-2912.3), (c) reader
refuses a foreign legacy file and accepts its own per-task file (AC-2912.2). GREEN adds (d) legacy read on exact
taskId match only, (e) CI branch lookup, (f) ambiguity exit 2, (g) start deletes only its own file.
GREEN cases (d)–(f) live in `__tests__/commands/review-sidecar-per-task-2912-green.test.ts`
(with a dangling per-task symlink and the correlated query on a foreign sidecar); (g) runs the real
`lifecycle start` re-anchor (`runTaskInit`) in `__tests__/commands/task-advance-gates.test.ts`.
Twins `diff` empty, `examples:check`, `kernel-plugin:check`, `check-self-dogfood`, bake snapshots,
`git check-ignore` exit 1.

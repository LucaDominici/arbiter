# #2926 — one shared "reviewed source changed" predicate

## Acceptance Criteria

- AC-2926.1: One shared predicate decides "source changed since the reviewed SHA", used by both the round opener and the completion binding.
- AC-2926.2: That predicate treats changes brought in by merging the base branch (content that is already on main) as not changing the reviewed source. A test-only or src change authored on the branch does count as changed.
- AC-2926.3: A regression test covers the #2908 sequence: review at X → test-only commit → merge main. The opener and the completion check must reach the same verdict.

## Non-goals

- The misleading "already covers this source" short-circuit after a repeat call (#2929).
- `checkBakeAfterTemplates` or any other `task.ts` code outside the review-round functions.
- A fetch inside the evidence-binding lib; a new `src/` export.

## Design

See `.claude/plans/PREMORTEM_2926.md` §1 and §5: `sourceChange` in `scripts/lib/evidence-binding.mjs`
compares HEAD with the reviewed SHA merged with `merge-base(HEAD, origin/main)`; the
`--correlated-sha` answer carries `sourceChanged`; `reviewedSourceChanged` in `task.ts` is deleted.

## Test strategy

RED file `__tests__/commands/review-source-binding-2926.test.ts` (AC-2926.2, AC-2926.3 on one fixture for
AC-2926.1), plus the targeted sweep in PREMORTEM §6.

# arbiter Public API

Spine for arbiter's public API surface. Generated snapshots live in
`../../api/` (api-extractor output); human-authored API docs live here.

## Generated snapshots (do NOT hand-edit)

Located under [`../../api/`](../../api/). Each file is regenerated by
api-extractor on every `npm run api:snapshot`. Hash markers
(`<!-- api-snapshot hash:... -->`) guard against drift.

| File                                                               | Surface                                              |
| ------------------------------------------------------------------ | ---------------------------------------------------- |
| [`../../api/compatibility.api.md`](../../api/compatibility.api.md) | Cross-language matrix + archetype declarations       |
| [`../../api/invariants.api.md`](../../api/invariants.api.md)       | Invariant catalog (INV-NN) public types              |
| [`../../api/plugin.api.md`](../../api/plugin.api.md)               | Plugin authoring API (apiVersion + entrypoint types) |

## API stability commitments

- Public types in the three `*.api.md` snapshots follow [`../SEMVER.md`](../SEMVER.md).
- Hook contracts in `../SYSTEM/HOOK-CONTRACTS.md` are stable across MINOR bumps.
- `plugin.api.md` `apiVersion` field signals breaking plugin API changes (MAJOR bump).

## When to update which surface

| Change kind             | Update path                                                       |
| ----------------------- | ----------------------------------------------------------------- |
| New CLI flag or command | api-extractor regenerates → review the diff in `compatibility`    |
| New invariant (INV-NN)  | Edit `../../AGENTS.md`; `invariants.api.md` regenerates           |
| New plugin entrypoint   | Edit `src/plugins/`; bump `apiVersion` in `plugin.api.md`         |
| New hook event          | Edit `../SYSTEM/HOOK-CONTRACTS.md` + reference in `plugin.api.md` |

# Sponsors & Funding

arbiter is an open-source project maintained by volunteers. Sponsorship helps sustain ongoing maintenance, feature development, and infrastructure.

## Why Sponsor

- Keep the project actively maintained
- Fund new features on the public [roadmap](PRODUCT/MILESTONES.md)
- Support the ecosystem tooling that thousands of AI-assisted development workflows depend on

## How to Sponsor

arbiter accepts sponsorships via **GitHub Sponsors**:

→ [github.com/sponsors/LucaDominici](https://github.com/sponsors/LucaDominici)

One-time and recurring tiers are both welcome.

## What Sponsorship Funds

| Category         | Examples                                                  |
| ---------------- | --------------------------------------------------------- |
| Infrastructure   | CI runner costs, GitHub Actions minutes, domain renewal   |
| Development time | Bug fixes, new stack support, invariant catalog expansion |
| Documentation    | Docs site hosting, copyediting, recipe authoring          |
| Community        | Moderation time, triage, first-responder support          |

## What Sponsorship Does NOT Confer

Sponsorship is **not** a commercial agreement. It does not grant:

- Roadmap influence or priority scheduling of specific features
- Priority issue response or SLA guarantees
- Fast-tracked PR review or merge rights
- Access to non-public code, data, or design documents

Roadmap decisions are made based on project goals and community need, independent of sponsor status.

## Sponsor List

Individual and corporate sponsors are listed on the GitHub Sponsors page.

Corporate sponsors wishing to display a logo on the docs site or README may open a PR to `docs/sponsors.md` with their logo (SVG/PNG, permissive license) and a link. Inclusion is at maintainer discretion and does not imply endorsement.

## FUNDING.yml

arbiter's `.github/FUNDING.yml` lists all active funding channels. See [.github/FUNDING.yml](../.github/FUNDING.yml).

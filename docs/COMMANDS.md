## Gate Commands

| Purpose        | Command                         |
| -------------- | ------------------------------- |
| L1 gate (fast) | `node scripts/check-all.mjs L1` |
| L2 gate (full) | `node scripts/check-all.mjs L2` |

> Run L1 before every commit, L2 before every push.

## Maintenance Rules

1. The inventory region above is generated — **do not edit it by hand**. Run `node scripts/gen-ssot-core.mjs` after adding, removing, or relabeling a canonical doc, and commit the result.
2. To add a doc to the set, give it the right frontmatter (`status: active` + a backbone `kind/*` tag, or a `canonical_id`); it is then picked up automatically.
3. INV-54 fails the gate if a listed file is missing; INV-108 fails it if a qualifying doc is absent from the inventory. Both run in `scripts/check-ssot-core.mjs` (L1).
4. ADRs belong under `docs/ADR/` (INV-107), not here.

# Java Stack Adapter Reference

**Issue:** #889 (F2-java) — Full Java/Spring adapter (94 crosswalk dimensions)
**Status:** Shipped (isStub: false)

## Overview

The Java stack adapter (`src/adapters/java.ts`) provides the full `StackAdapter` implementation
for Java/Spring projects. It replaces the stub introduced in #881 (W5 — Stack Adapter Model).

## Adapter Contract

| Field / Method    | Value / Behaviour                                          |
| ----------------- | ---------------------------------------------------------- |
| `language`        | `'java'`                                                   |
| `isStub`          | `false`                                                    |
| `lintCommand()`   | `'mvn checkstyle:check pmd:check'`                         |
| `formatCommand()` | `null` — Checkstyle enforces formatting; no separate step  |
| `languageHooks()` | `[]` — Java hooks delegated to `getLanguageHooks('java')`  |
| `supportsCoverage()` | `true` — JaCoCo                                         |
| `supportsMutation()` | `true` — Pitest                                         |

## Language Hooks (via getLanguageHooks)

Java-specific hooks are defined in `src/detectors/language-hooks.ts` and emitted by
`getLanguageHooks('java')`. The adapter's `languageHooks()` returns `[]` to avoid
duplication — per the `StackAdapter` interface contract: "Does NOT replace common hooks
from `getLanguageHooks()`."

| Hook                        | Enforces                                                       |
| --------------------------- | -------------------------------------------------------------- |
| `check-no-raw-types.mjs`    | No raw generic types (e.g., `List` must be `List<String>`)    |
| `check-no-mockmvc.mjs`      | MockMvc is forbidden — use RestAssured for integration tests  |
| `check-no-orphan-todo.mjs`  | Every TODO must reference a task ID (common hook, all langs)  |

## Coverage: JaCoCo

JaCoCo configuration is generated by `src/generators/coverage.ts`:
- **Gradle projects:** `gradle/jacoco.gradle` (from `coverage/jacoco.gradle.ejs`)
- **Maven projects:** `docs/coverage/jacoco-maven-setup.md` (setup guidance doc)

## Mutation: Pitest

Pitest configuration is generated by `src/generators/mutation.ts` (L3 governance):
- **Gradle projects:** `gradle/pitest.gradle` (from `mutation/pitest.gradle.ejs`)
- **Maven projects:** `docs/mutation/pitest-maven-setup.md` (setup guidance doc)

## Architecture Enforcement: ArchUnit

ArchUnit test scaffolding is generated by `src/generators/archunit.ts`. Templates live
in `src/templates/archunit/` (14 templates covering hexagonal, NoMockMvc, RestAssured, etc.).

Activated when: `language === 'java'` and `basePackage` is set.

## Deferred Scope

The following were considered for this PR but excluded per CANON-16 (no consumer generator):

- `src/templates/java/checkstyle.xml.ejs` — standalone Checkstyle config template
- `src/templates/java/pmd.xml.ejs` — standalone PMD ruleset template

These will be added in a follow-up when a generator consumes them during `arbiter init`.

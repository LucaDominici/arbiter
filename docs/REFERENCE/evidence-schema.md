# Reference: Evidence Bundle Schema

> **Target:** Projects generated by arbiter
> **Schema file:** `schemas/evidence-bundle.schema.json`
> **Invariant:** INV-90 — Evidence bundle schema compliance
> **Gate script:** `scripts/check-evidence-bundle.mjs`

---

## Quick Start

When closing a task, create `.evidence/task-#NNN/bundle.json`:

```json
{
  "taskId": "#883",
  "timestamp": "2026-05-19T10:00:00.000Z",
  "gateResult": "pass",
  "redTestPath": "__tests__/scripts/check-evidence-bundle.test.ts",
  "greenTestPath": "__tests__/scripts/check-evidence-bundle.test.ts",
  "artifacts": []
}
```

Run the validator:

```bash
node scripts/check-evidence-bundle.mjs
```

---

## Fields

### `taskId` (required)

Type: `string` matching `^#[0-9]+$`

The GitHub issue number that this task corresponds to, e.g. `"#883"`.

### `timestamp` (required)

Type: ISO 8601 date-time string

When this evidence bundle was recorded. Use `new Date().toISOString()` to generate.

### `gateResult` (required)

Type: `"pass"` | `"fail"`

The result of running the quality gate (`node scripts/check-all.mjs gate`) at the time this
bundle was finalized. A `"fail"` result is valid schema-wise — it records that the gate was
red at bundle creation time (the human must decide whether to proceed).

### `redTestPath` (required)

Type: non-empty string

Relative path from the repository root to the test file that was written in the **red phase**
(tests were written before implementation and initially failed). This field is mandatory to
enforce TDD discipline.

### `greenTestPath` (required)

Type: non-empty string

Relative path from the repository root to the test file that passes after implementation.
May be identical to `redTestPath` if the same file was used throughout.

### `artifacts` (required, may be empty)

Type: array of `Artifact` objects

Optional list of supplementary files. An empty array `[]` is valid.

#### Artifact fields

| Field      | Required | Type   | Description                                               |
| ---------- | -------- | ------ | --------------------------------------------------------- |
| `name`     | yes      | string | Human-readable label, e.g. `"coverage-report"`            |
| `path`     | yes      | string | Relative path from repo root, e.g. `"coverage/lcov.info"` |
| `mimeType` | no       | string | Optional MIME type, e.g. `"text/plain"`, `"text/html"`    |

## Validation

The gate script `scripts/check-evidence-bundle.mjs`:

- Scans `.evidence/task-*/` for `*.json` files
- Validates each against the schema
- Exits 0 with a vacuous pass message when no bundles exist
- Exits 1 and reports all errors when any bundle is invalid

### Running manually

```bash
# Default: validates .evidence/ against schemas/evidence-bundle.schema.json
node scripts/check-evidence-bundle.mjs

# Custom paths:
node scripts/check-evidence-bundle.mjs \
  --evidence-dir=path/to/.evidence \
  --schema=path/to/schema.json

# Help:
node scripts/check-evidence-bundle.mjs --help
```

---

## Integration with Arbiter Gate

INV-90 is wired at the **L2 gate** level. It runs as part of `gate` and `full` subcommands:

```bash
node scripts/check-all.mjs gate   # includes evidence-bundle check
node scripts/check-all.mjs check  # does NOT include evidence-bundle check (L1 only)
```

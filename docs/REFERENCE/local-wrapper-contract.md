# Local-Wrapper Contract (INV-87, W3)

Arbiter ships a POSIX Makefile + `run.sh` shim as the **local CI parity façade**. This document defines the contract between the wrapper and the CI workflow layer.

## POSIX Makefile Discipline

The Makefile must remain POSIX-compatible (runs on BSD make and GNU make without differences). The following constructs are **forbidden**:

| Construct                   | Why forbidden |
| --------------------------- | ------------- |
| `:=` immediate assignment   | GNU extension |
| `?=` conditional assignment | GNU extension |
| `ifeq` / `ifdef` / `else`   | GNU extension |
| `$(shell …)`                | GNU extension |
| `$(wildcard …)`             | GNU extension |
| `.SECONDEXPANSION`          | GNU extension |
| `%` pattern rules           | GNU extension |
| Target-specific variables   | GNU extension |

The test suite (`__tests__/templates/local-wrapper.snapshot.test.ts`) fails CI if any forbidden construct appears in the rendered Makefile.

## Target → Script Mapping

| Make target        | Script invocation                             | CI equivalent     |
| ------------------ | --------------------------------------------- | ----------------- |
| `help`             | `@echo ...` (prints target list)              | Local only        |
| `check`            | `node scripts/check-all.mjs check`            | L1 fast check     |
| `gate`             | `node scripts/check-all.mjs gate`             | L1 + L2 gate      |
| `ci`               | Alias for `gate`                              | PR gate           |
| `full`             | `node scripts/check-all.mjs full`             | Full coverage run |
| `simulate-nightly` | `node scripts/check-all.mjs simulate-nightly` | Nightly (W10)     |
| `simulate-weekly`  | `node scripts/check-all.mjs simulate-weekly`  | Weekly (W10)      |
| `evidence`         | `node scripts/done-evidence.mjs`              | Local only        |
| `clean`            | Remove `.arbiter/gate-pass.json` + tmp files  | Local only        |

## Parity Contract

**INV-87**: Makefile `.PHONY` targets (after excluding local-only targets) must be a subset of CI workflow job names.

Local-only targets excluded from the comparison:

- `help`, `clean`, `evidence` — no CI counterpart required
- `simulate-nightly`, `simulate-weekly` — deferred to W10

Enforcement: `scripts/check-local-ci-parity.mjs` runs two checks:

1. **Static check (L1)** — parses Makefile `.PHONY` and `.github/workflows/*.yml` job names, compares the sets. Invoked at L1 with `PARITY_STATIC_CHECK_ONLY=1`. Skip-neutral when either is absent (pre-W4 state: empty workflows dir exits 0).
2. **Runtime check (L2)** — compares `parityContentHash` between local `.arbiter/gate/local-result.json` and the latest CI gate-result artifact (existing INV-59 / INV-81 check). The full script also re-runs the static check before the runtime hash comparison.

## `make ci` = `make gate`

`ci` is a POSIX dependency alias (`ci: gate`). It exists so contributors can type `make ci` (CI-vernacular) and get the same behavior as `make gate`. Both run `node scripts/check-all.mjs gate`.

## Selective gating for local iteration (self-only, #2094)

`ARBITER_SELECTIVE_GATE=1 node scripts/check-all.mjs gate --level L2` skips checks whose
`scripts/lib/gate-affects-registry.mjs` entry proves untouched by the current diff vs
`origin/main` (working tree + untracked files, so it's meaningful pre-commit). Coarse
buckets only — docs-only, `.github/**`-only, `src/templates/**`-only — everything else
defaults to always-run. A blacklist (`package.json`, `scripts/lib/**`, the gate script
itself, etc.) forces the full gate when a change could plausibly affect every check.

This is a **local speed tool only**. CI and any pre-push/pre-merge invocation always run
the full, unfiltered gate — the flag has no effect under `CI=true`/`GITHUB_ACTIONS=true`,
and no merge is ever gated by a selective run. It is arbiter-self-specific (reasons about
arbiter's own ~145-check self-gate) and is not part of what `arbiter init`/`arbiter update`
emits to consumer projects.

## W10 Deferral: simulate-nightly / simulate-weekly

The `simulate-nightly` and `simulate-weekly` targets dispatch to `node scripts/check-all.mjs simulate-nightly` / `simulate-weekly`. The `check-all.mjs` implementations for these subcommands are **stub bodies** (print a deferred-to-W10 message and exit 0). W10 will implement the full nightly/weekly simulation; the Makefile targets are wired now so contributors can call them without breaking workflows.

## `.env.example` Variable Reference

Generated by `arbiter init` alongside the Makefile. Copy to `.env` (gitignored) and edit as needed.

| Variable               | Default             | Purpose                              |
| ---------------------- | ------------------- | ------------------------------------ |
| `ARBITER_LEVEL`        | `L1`                | Governance level for local gate runs |
| `ARBITER_EVIDENCE_DIR` | `.arbiter/evidence` | Path to evidence artifact directory  |
| `NODE_ENV`             | (unset)             | Node.js environment string           |

## arbiter init

`arbiter init` emits:

- `Makefile` — POSIX wrapper (skip if exists)
- `run.sh` — POSIX shim, `chmod 755` (skip if exists)
- `.env.example` — environment variable reference (skip if exists)

Generators: `local-wrapper` (Makefile + run.sh), `env-template` (.env.example). Both are always-enabled in the generator registry and governance-invariant (same output at L1/L2/L3).

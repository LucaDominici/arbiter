# Hook Script Inventory

Reference for all Claude Code hooks generated by Arbiter. Hooks enforce governance invariants at edit time, preventing violations before they reach the gate or CI.

Hooks are configured in `.claude/settings.json` and fire on Claude Code tool events.

All hooks are Node.js `.mjs` files — no bash required, no `chmod` needed, works on Windows without WSL.

---

## Hook Architecture

```
.claude/
  hooks/
    lib.mjs                   # Shared utilities (logging)
    stop-dangerous.mjs        # PreToolUse → Bash
    enforce-read-only.mjs     # PreToolUse → Edit|Write
    pre-edit-ssot-guard.mjs   # PreToolUse → Edit|Write
    post-commit-check.mjs     # PostToolUse → Bash
    check-no-orphan-todo.mjs  # PostToolUse → Edit|Write
    check-no-any.mjs          # PostToolUse → Edit|Write (TypeScript only)
    check-no-unwrap.mjs       # PostToolUse → Edit|Write (Rust only)
  settings.json               # Hook registration + permissions
```

Hooks read tool context from environment variables:

| Variable                    | Content                    |
| --------------------------- | -------------------------- |
| `CLAUDE_TOOL_INPUT_COMMAND` | The bash command being run |
| `CLAUDE_TOOL_INPUT_PATH`    | The file path being edited |

## Template-Generated Hooks

These hooks are generated from EJS templates in `src/templates/claude/hooks/`.

### `lib.mjs`

| Property            | Value                                    |
| ------------------- | ---------------------------------------- |
| **Source template** | `src/templates/claude/hooks/lib.mjs.ejs` |
| **Event**           | N/A (imported by other hooks)            |
| **Purpose**         | Shared logging utilities                 |
| **Invariant**       | None                                     |
| **Languages**       | All                                      |

Provides `logInfo`, `logWarn`, `logError` functions. Writes to `.claude/hooks/logs/hook-events.log`.

### `post-commit-check.mjs`

| Property            | Value                                                  |
| ------------------- | ------------------------------------------------------ |
| **Source template** | `src/templates/claude/hooks/post-commit-check.mjs.ejs` |
| **Event**           | `PostToolUse` -> `Bash`                                |
| **Purpose**         | Verify commit message follows conventional format      |
| **Invariant**       | Commit convention (AGENTS.md Commit Convention)        |
| **Languages**       | All                                                    |
| **Timeout**         | 3 seconds                                              |
| **Blocking**        | No (warning only)                                      |

Triggers only on `git commit` commands. Checks the last commit message against the pattern:

```
^(feat|fix|refactor|test|docs|ci|chore|perf|style|build|revert)(\([^)]+\))?: .{1,72}$
```

Uses `spawnSync('git', ['log', '-1', '--format=%s'])` to read the last commit.

## Code-Generated Hooks (Language-Specific)

These hooks are generated programmatically by `src/detectors/language-hooks.ts` and written as standalone `.mjs` files during `arbiter init`.

### `check-no-orphan-todo.mjs`

| Property      | Value                                                       |
| ------------- | ----------------------------------------------------------- |
| **Source**    | `src/detectors/language-hooks.ts` (`COMMON_NO_ORPHAN_TODO`) |
| **Event**     | `PostToolUse` -> `Edit\|Write`                              |
| **Purpose**   | Every TODO must reference a task ID                         |
| **Invariant** | INV-06                                                      |
| **Languages** | All                                                         |
| **Timeout**   | 5 seconds                                                   |
| **Blocking**  | Yes (exit 1)                                                |

Scans the edited file for `TODO` not followed by `(#NNN)`. Fails if an orphan TODO is found.

**Pattern matched:** `\bTODO\b` without a `(#<digits>)` suffix.

### `check-no-any.mjs`

| Property      | Value                                           |
| ------------- | ----------------------------------------------- |
| **Source**    | `src/detectors/language-hooks.ts` (`TS_NO_ANY`) |
| **Event**     | `PostToolUse` -> `Edit\|Write`                  |
| **Purpose**   | No `any` type in TypeScript source files        |
| **Invariant** | INV-04 (TypeScript)                             |
| **Languages** | TypeScript only                                 |
| **Timeout**   | 5 seconds                                       |
| **Blocking**  | Yes (exit 1)                                    |

Only activates for `.ts` and `.tsx` files. Fails if an explicit `any` type annotation (`: any`) is found.

**Pattern matched:** `:\s*any\b`

### `check-no-unwrap.mjs`

| Property      | Value                                                |
| ------------- | ---------------------------------------------------- |
| **Source**    | `src/detectors/language-hooks.ts` (`RUST_NO_UNWRAP`) |
| **Event**     | `PostToolUse` -> `Edit\|Write`                       |
| **Purpose**   | No `.unwrap()` calls in Rust source files            |
| **Invariant** | INV-04 (Rust)                                        |
| **Languages** | Rust only                                            |
| **Timeout**   | 5 seconds                                            |
| **Blocking**  | Yes (exit 1)                                         |

Only activates for `.rs` files. Fails if `.unwrap()` is found.

**Pattern matched:** `\.unwrap\(\)`

## Permissions (settings.json)

The generated `settings.json` also configures tool permissions:

**Allow list** (varies by `buildTool`):

| Build Tool | Allowed Commands               |
| ---------- | ------------------------------ |
| All        | `git *`, `./scripts/*`, `gh *` |
| `npm`      | `npm run *`, `npx *`, `node *` |
| `cargo`    | `cargo *`                      |
| `gradle`   | `./gradlew *`, `gradle *`      |

**Deny list** (all languages):

| Command            | Reason                           |
| ------------------ | -------------------------------- |
| `rm -rf /*`        | Prevent root filesystem deletion |
| `sudo:*`           | Prevent privilege escalation     |
| `git push --force` | Prevent history rewriting        |

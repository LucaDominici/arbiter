# Agent Rules Export Reference

**Removed.** The multi-tool `agent-rules` export command (and the `cursor` /
`copilot` / `aider` / `windsurf` intermediate-format emitters it drove) was cut
from the command surface in the T2 cathedral-cut (`src/agent-rules/` deleted
wholesale — it had no consumer besides its own CLI registration). This page
is kept as a pointer for readers who land here from an old link.

Per ADR-095 (`docs/internal/ADR/095-supported-ai-tools-claude-codex.md`),
`claude` and `codex` are arbiter's only supported end-to-end targets. Their
governance rules are generated directly — not via the removed export — by:

- `src/generators/claude.ts` — emits `.claude/` (hooks, skills, commands, rules).
- `src/generators/agents-md.ts` — emits the root `AGENTS.md` governance file.

There is no per-tool intermediate JSON format and no drift-detection command
(`agent-rules verify`) anymore: `AGENTS.md` and `.claude/` are regenerated by
`arbiter update`, and staleness is caught the same way as any other emitted
artifact (`arbiter diff`, dogfood gates).

If you previously relied on the `cursor`/`copilot`/`aider`/`windsurf` static
rule-file exports, those targets are no longer emitted by arbiter; write
`.cursorrules` / `<project>/.github/copilot-instructions.md` / `CONVENTIONS.md` /
`.windsurfrules` by hand, or keep them in sync with `AGENTS.md` manually.

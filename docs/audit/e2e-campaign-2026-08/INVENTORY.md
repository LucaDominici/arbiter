## 0. Method — how coverage was classified

The FEATURE_MATRIX `test_ref` column is **not** usable as a coverage signal: 46 of 55 rows are
`Partial` with an empty `test_ref`, yet e.g. REQ-042 (doctor) has 9 test files on disk. Coverage
below is derived from the test tree, not from the matrix column.

Four buckets, mechanically derived:

| Bucket   | Definition                                                                                                                                 | How identified                                                                                                                           |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------- |
| **E2E**  | A real subprocess is spawned against the packaged `dist/cli.js` (or the _generated_ `scripts/check-all.mjs`) in a tmpdir / fixture project | `grep -rl "dist/cli.js" __tests__/` → 14 files; plus `fixture-functional.test.ts` which spawns `node <fixture>/scripts/check-all.mjs L1` |
| **FIX**  | Fixture-integration: in-process `runInit()` against `__tests__/fixtures/real-projects/*`, asserting emitted file content                   | `__tests__/integration/e2e/{bake,native}/` (19 `bake` + 3 `snapshot` fixtures — emission only, gate never executed)                      |
| **UNIT** | In-process unit or integration test only; never the real binary, never a real generated gate                                               | everything else under `__tests__/`                                                                                                       |
| **NONE** | No automated test located                                                                                                                  | grep miss                                                                                                                                |

**The complete real-E2E surface of this repo (14 files).** Everything else is UNIT or FIX:

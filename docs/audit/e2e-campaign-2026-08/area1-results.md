# AREA 1 — Bootstrap, detection & stack support (`arbiter init`) — E2E results

Binary under test: `node /home/luca/work/repos/arbiter/dist/cli.js` (v0.5.0, built from `main` @ 9e57b4c1).
All targets: fresh `mktemp -d /tmp/rtm-a1-*` sandboxes, real `git init` + seed commit
(`git -c core.hooksPath=/dev/null commit` so my own scaffolding never triggers the generated hooks).
Helper used throughout: `arb() { node /home/luca/work/repos/arbiter/dist/cli.js "$@"; }`.

**Environment available:** node 22.21.1 / npm 10.9.8, python 3.12.3 + pytest 8.4.2 + ruff 0.4.10,
go 1.25.11, rust 1.94, java 21 + gradle 8.8. Missing: `mvn`, `kotlinc`.

**Verdict rule applied** (fixed before the first gate run): a gate red caused by an absent
toolchain/dependency in the sandbox → `BLOCKED(env)`. A gate red caused by something _arbiter emitted_
(broken config, missing wrapper, unbounded file walk, wrong wiring) → `FAIL`.

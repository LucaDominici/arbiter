# PROD Environment Checklist — arbiter

_Generated by arbiter. Complete before every production deployment._

> **Purpose**: Pre-deployment verification. Deliver to the DevOps/Infra team before go-live.

---

## § 1 — Code & Build

- [ ] All acceptance criteria on the deployment ticket are closed
- [ ] PR reviewed and approved (minimum 2 reviewers for L3 governance)
- [ ] Gate passes: `node scripts/check-all.mjs L2` exits 0
- [ ] Build artifact tagged with the release version (e.g., `v1.2.3`)
- [ ] No critical or high CVEs in `npm audit` / `mvn verify` / equivalent

---

## § 2 — Database / Migrations

- [ ] Migration files committed alongside application code
- [ ] Migration runs successfully on a staging DB snapshot
- [ ] Rollback migration documented and tested (if schema change)
- [ ] No irreversible DDL (DROP COLUMN, TRUNCATE) without backup confirmed

---

## § 3 — Configuration & Secrets

- [ ] All required environment variables documented in `.env.example`
- [ ] Secrets provisioned in secret manager (not hardcoded or in version control)
- [ ] Config drift check: staging config matches production template
- [ ] Health check URLs configured for liveness/readiness probes

---

## § 4 — Infrastructure

- [ ] Container image built from tagged commit (not from `main` HEAD)
- [ ] Container registry access verified (pull secret / service account)
- [ ] CPU and memory limits set appropriately for expected load
- [ ] Autoscaling rules configured (min/max replicas)
- [ ] Load balancer / reverse proxy config updated if routing changed

---

## § 5 — Observability

- [ ] Structured logging in place (no raw print statements)
- [ ] Log level set to INFO in production (DEBUG disabled)
- [ ] Error alerting configured (alert fires within 2 min of error spike)
- [ ] Dashboards exist: latency, traffic, error rate, saturation (4 golden signals)
- [ ] Distributed tracing propagates correlation IDs across service calls

---

## § 6 — Security

- [ ] `gitleaks detect` passes (no secrets in code)
- [ ] PII scan passes: `node scripts/pii-scan.mjs`

---

## § 7 — Deployment Execution

- [ ] Maintenance window communicated (if applicable)
- [ ] Rollback plan confirmed (see `docs/runbooks/rollback.md`)
- [ ] On-call engineer available during deployment
- [ ] Deployment proceeds → verify health probes within 5 min
- [ ] Smoke test critical user flows after deployment

---
